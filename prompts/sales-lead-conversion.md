# Sales & Lead Conversion Prompts

## Prompt 1

Create a sales qualification framework for a [business type]. Include questions to identify budget, need, urgency, decision-making authority, and buying intent.

## Prompt 2

Create a sales call script for converting qualified leads into customers for [product/service]. Include opening, discovery questions, presentation, objection handling, and closing.

## Prompt 3

Generate responses to the 10 most common objections customers have when buying [product/service].

## Prompt 4

Create a follow-up sequence for a qualified lead who attended a sales call but did not purchase. Include messages for Day 1, Day 3, Day 7, and Day 14.

## Prompt 5

Create a lead scoring system for a [business type]. Assign scores based on engagement, budget, urgency, requirements, and buying intent.

## Prompt 6

Create a sales pipeline for a service business from New Lead → Qualified → Contacted → Appointment → Proposal → Negotiation → Won/Lost.

## Prompt 7

Write a persuasive response to a customer who says, "Your price is too high." Handle the objection without immediately offering a discount.

## Prompt 8

Create a consultation call framework that helps a salesperson understand the customer's current situation, problems, goals, and desired outcome.

## Prompt 9

Create a lead reactivation campaign for old leads who did not purchase. Include 5 different reactivation messages using different value propositions.
